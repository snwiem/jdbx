# Security policy

## Report a vulnerability

Please **do not open a public issue** for a security problem.

Use GitHub private vulnerability reporting: open the [Security tab](https://github.com/snwiem/jdbx/security) and choose **Report a vulnerability**. Only you and the maintainer can see the report.

Please include:

- what the problem is and what it can do
- the steps to reproduce it
- the jdbx version (`jdbx --version`), your Java version and your operating system

Do not send real passwords, tokens or customer data.

## What to expect

jdbx is a hobby project. The maintainer works on it in free time and can give **no guaranteed response time**. The aim is to answer within a few days, and to fix real problems as soon as possible. After a fix, the problem is made public in a release note or an advisory. Your name is shown if you want it.

## Supported versions

Only the [latest release](https://github.com/snwiem/jdbx/releases/latest) gets fixes.

## Know the risk

Most of the code is written by AI and only partly reviewed (see the [README](README.md)). jdbx handles database passwords and runs SQL Statements. Use it at your own risk.
